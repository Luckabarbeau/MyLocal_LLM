## Scope and decision

This is a read-only implementation/evidence audit, except for this new document. No model execution, compilation, GPU allocation, benchmark rerun, download, or existing-file edit was performed. Existing modifications to `mini_llm/heterogeneous_production.py`, its untracked `.bak`, and untracked `strata_launch_bench_capture.sh` were preserved.

**Reuse the existing implementation; do not start a second loader, expert scheduler, or server. WP0 baseline is NOT complete.** The user supplied the WP0 specification: reproducible Strata configuration/version, exact checkpoint hashes, frozen local execution configuration, numerical fixtures, and throughput/resource baseline. This is the supplied acceptance specification, not missing requirements merely because repository text did not previously contain a WP0 definition. The older numerical contract and the newer pinned Strata prompt arithmetic are different reference policies and must remain explicitly distinguished.

Paths below are relative to repository root. Historical reports are evidence of recorded runs, not claims that this audit reran them. ## Exact readiness gaps preventing a defensible WP0 sign-off

1. **Supplied WP0 specification; incomplete acceptance evidence:** reproducible Strata configuration/version, exact checkpoint hashes, frozen local execution configuration, numerical fixtures, and throughput/resource baseline are required. Implement and collect these deliverables; do not describe the specification as missing. Record fixture-specific tolerances and workload details without inventing additional acceptance targets; the historical50 forwards/s target is not automatically WP0's definition.
2. **Incomplete immutable provenance:** full shard payload hashes/checkpoint revision and official model-definition authority remain open. Bind the selected numerical policy, source snapshot, external binary/library hashes, compiler flags and final local source identities into one reproducible run manifest. A pin string or current-tree source hash alone does not identify past execution.
3. **Missing raw baseline artifacts:** restore or reproducibly regenerate the absent production-recovery HTTP evidence and 0335 raw results in fresh output paths. Retained summary Markdown is insufficient for independently recomputing timing distributions and resource accounting.
4. **Unclosed numerical acceptance:** independent full-model several-percent logit differences remain recorded. Obtain matched-input first-divergence attribution under explicitly matched activation/KV/state precision and expert execution policy; agree tolerances before testing. Exact local graph capture and matching forced token IDs do not close this. Longer/mixed-placement and populated-context validation are separate missing gates.
5. **No demonstrated integrated native-port baseline:** reusable CUDA expert/dense/QSA/pipeline components have narrow declared contracts. Dense GEMM is still correctness scaffolding; QSA starts at projected inputs; long-stream orchestration excludes upstream alternate dispatch/planner paths. There is no inspected end-to-end artifact establishing their composed native engine matches the selected Strata graph, scheduler and numerical policy or improves prompt performance.
6. **No apples-to-apples accepted performance baseline:** match exact prompt/continuation IDs, cold/warm state, effective context occupancy, quantization, KV, complete routing/no drafts, cache bytes/placement, workers/affinity, and limits. Report prefill, client TTFT, decode forwards/s and emitted tokens/s separately, with repeated interleaved trials and RAM/VRAM/IO telemetry. Historical decode remains below50/s and newer HTTP reports show large prefill deficits; neither is a new benchmark of these CUDA ports.
7. **Current build/test execution not established:** this audit checked availability, not compilation or actual CuPy launch. Run focused native tests with explicit device selection and retain pass/skip reasons, then composition tests under memory guards. External GGML ABI/library presence and installed-engine binary identity require explicit verification. Do not infer GPU validation from test collection.

### External dependencies versus remaining local work

External provenance dependencies: authoritative immutable checkpoint/model-definition revision; shipped Strata compiler/build metadata; missing historical raw artifacts if their exact past runs must be recovered. Missing historical artifacts may instead be replaced by explicitly new measurements, never invented reconstruction.

Remaining local implementation/evidence work: stream-hash the two available payloads in a separately IO-budgeted run; pin pack/profile/tokenizer identities and resolved Strata settings; freeze complete effective local model execution switches, KV/placement/cache/worker affinity and exact input/continuation IDs; persist matched-policy numerical fixtures and resolve independent-model discrepancy; complete native composition validation; run repeated interleaved throughput/resource baselines under the existing isolation harness. These are not external model-availability blockers.

Harness inspection: `strata_launch_bench_capture.sh` records runtime/API/standard-v1 evidence but uses `--restart`, leaves a server running, defaults context262144, and does not itself require strict no-drafting. It was deliberately **not run**. `scripts/probe_0310_strata_comparison.py` provides fixed-context1024 complete-top10/no-draft controlled replay but explicitly uses INT8 KV, so is not the local FP32 oracle. `scripts/run_0290_isolated_benchmark.py` verifies cgroup memory/swap/pressure controls and is the reusable entry point for future full-model runs. No current isolation failure is claimed: none was attempted here.

**WP0 remains NOT complete:** component numerical evidence and current identities are now captured; exact payload identity, a frozen whole-model execution contract and accepted throughput/resource measurements are not.
