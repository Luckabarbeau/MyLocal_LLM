**The target of 50 complete decode forwards/s is UNMET.** The latest 0317 responses
are **41.438964 / 39.940459 forwards/s**; neither recurrent chaining nor complete
QSA capture demonstrates a hot full-model gain. Cooperative QSA remains opt-in
and **NOT quality accepted**, despite substantial standalone operator speedups.

This report analyzes existing artifacts only: no new model, GPU, or scheduler run.

## Per-patch implementation ledger

### 0310 — Installed-engine Strata harness
- **Objective/files/interface:** `scripts/probe_0310_strata_comparison.py` and
  `tests/test_0310_strata_comparison.py`; binary stdin GEN/T/DONE protocol,
  exact retained IDs, strict progress/counter validation, bounded deadlines,
  exclusive outputs, process snapshots, and QUIT/terminate/kill cleanup.
- **Validation:** **81 harness passes**, now confirmed by the retained final CPU
  JUnit's `tests.test_0310_strata_comparison` class; not rerun by this analyzer.
- **Performance/limit:** separate rates above; request validation cannot override
  failed cleanup. **Next dependency:** repeat clean matched subsets with placement
  and arithmetic differences documented before claiming engine-level superiority.

### 0311 — PLE attribution, not a mathematical change
- **Objective/files/interface:** `scripts/probe_0311_local_ple.py`,
  `tests/test_0311_local_ple.py`; `PLETimer` wraps embedding/rows/decoder scopes,
  separates prefill/decode, uses embedding-thread major faults, restores hooks.
- **Validation:** **14 diagnostic passes**, now confirmed by final CPU JUnit.
  No added CUDA event/synchronization; inclusive host timings are not additive.
- **Evidence/limit:** local v2 response: 358 embeddings, **0.939782890 s**, **4282**
  embedding-thread major faults. Local v1 parent exit 1 remains a failed artifact.
  **Next dependency:** isolate bounded row acquisition from reference IQ4_NL math.

### 0312 — Bounded PackedRowReader and batched PLE lookup
- **Objective/files/interface:** `mini_llm/ops/packed_row_reader.py`,
  `mini_llm/external/qwen4exp_ple.py`, `tests/test_0312_{packed_row_reader,ple_batched_io}.py`;
  `read_batch` ≤16 rows, ≤8 workers, immutable bounded LRU, ordered duplicates,
  owned bytes, validated offsets, partial-read/EINTR handling, explicit close.
  `MINI_LLM_PLE_BATCHED_ROWS` opts into one `(16,160)` IQ4_NL decode; hashes,
  row order, PLE recurrence/EOS/reset mathematics remain unchanged.
- **Validation:** JUnit `0312_cpu_tests_v1.xml`: **123 passed, 2 skipped**;
  includes **55 reader + 4 PLE** tests. `0312_gpu_tests_v1.xml`: **9 passed,
  20 skipped**; skipped model tests are not passes. PLE fixtures check exact rows,
  output/history, request reset, bounds, failures and lifecycle.
- **Evidence/limit:** profile response embedding time **0.188449254 s**, repeat
  **0.041290648 s**, both with **zero embedding-thread major faults**. Different
  cache warmth prevents treating the cold comparison as a matched speedup.
  RANDOM advice/pread still uses OS page cache; logical bytes are not disk traffic.
  **Next dependency:** retain matched control/candidate timing; no hot gain shown.

### 0313 — Complete recurrent block graph with native CPU service
- **Objective/files/interface:** `mini_llm/external/qwen4exp_recurrent_block_graph.py`,

## Critical path, memory and reproduction

`0313_critical_path_v1.json` covers 16 traced tokens: GPU span **443.334255/16 =
27.708391 ms/token**, non-wait operation union **215.746344/16 = 13.484147 ms**,
wait-kernel sum **137.167184/16 = 8.572949 ms**, **992/16 = 62 graph launches/token**.
These overlap CPU/API spans and are **not an additive exclusive breakdown**.
Remaining producer/GPU gaps are a hypothesis, **not proved recoverable**; negative
0315/0317 hot results must constrain any proposed explanation of the remaining gap.

Memory authority is each isolation **`guard.jsonl`**, not systemd's displayed
~2 MB parent-process peak. Across 33 guards, recorded reserve checks preserve
**12 GiB**; `memory.events` high/max/oom/oom_kill remain zero. Some runs have
nonzero PSI (Strata profile max some/full avg10 **1.26/1.26**); do not claim no pressure.
